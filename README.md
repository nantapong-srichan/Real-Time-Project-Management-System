# Real-time Learning & Project Management System

เว็บแอปสำหรับจัดการการเรียนการสอนของสถาบัน รวมถึงดูรายรับรายจ่ายของสถาบันและของเว็บไซต์ โดยแยกข้อมูลออกเป็นแต่ละส่วนเพื่อให้ดูรายละเอียดและภาพรวมร่วมกันได้ในระบบเดียว

ระบบรองรับโครงสร้างผู้ใช้งานหลายบทบาท เช่น ผู้ดูแลระบบ ผู้สอน สมาชิก และผู้เรียน พร้อมวางโครงสร้างสำหรับการจัดการคอร์ส บทเรียน การสอบ และข้อมูลทางการเงินของแต่ละส่วน

## จุดประสงค์ของแอป

แอปพลิเคชันนี้มีเป้าหมายเพื่อช่วยให้สถาบันสามารถ:

- จัดการคอร์ส บทเรียน และเนื้อหาการเรียนการสอน
- จัดการผู้เรียน ผู้สอน สมาชิก และสิทธิ์การใช้งาน
- สร้างแบบทดสอบ จับเวลา บันทึกคำตอบ และดูผลคะแนน
- ดูความคืบหน้าการเรียนและข้อมูลการลงทะเบียน
- แยกรายรับรายจ่ายของสถาบันออกจากรายรับรายจ่ายของเว็บไซต์
- ดูข้อมูลแต่ละส่วนแยกกัน พร้อมดูภาพรวมเพื่อช่วยติดตามการดำเนินงาน

## ฟีเจอร์หลัก

### ฝั่งผู้เรียน

- Dashboard สรุปความคืบหน้า
- รายการคอร์สและบทเรียน
- ห้องทำแบบทดสอบออนไลน์
- ระบบจับเวลาและบันทึกคำตอบ
- รายงานคะแนนหลังสอบ
- สถิติและแนวโน้มผลการเรียน
- ดูข้อมูลการลงทะเบียนและการเรียนของผู้เรียน

### ฝั่งผู้สอนและผู้ดูแลระบบ

- จัดการคอร์สและบทเรียน
- จัดการคลังคำถาม
- สร้างและเผยแพร่ชุดแบบทดสอบ
- ตรวจสอบผลการทำแบบทดสอบ
- จัดการสมาชิกและสิทธิ์การใช้งาน
- ดูรายรับรายจ่ายของสถาบัน
- ดูรายรับรายจ่ายของเว็บไซต์
- ดูรายงานภาพรวมแยกตามส่วนของระบบ

## เทคโนโลยี

### Frontend

- Next.js
- React
- TypeScript
- CSS แบบ Responsive

### Backend

- NestJS
- TypeScript
- Prisma ORM
- REST API

### Database

- PostgreSQL

เทคโนโลยีที่ยังเป็นแผนงาน เช่น Redis และ WebSocket ยังไม่ถือเป็นส่วนที่ใช้งานจริงใน repository ปัจจุบัน

## โครงสร้างโปรเจกต์

```text
.
├── frontend/              # Next.js + React application
│   ├── app/               # App Router pages and styles
│   └── package.json
├── backend/               # NestJS API application
│   ├── prisma/            # Database schema
│   ├── src/               # API modules and services
│   └── package.json
├── index.html             # Prototype เดิมสำหรับอ้างอิง UI
├── styles.css             # Styles ของ prototype เดิม
└── app.js                 # Interaction ของ prototype เดิม
```

## วิธีติดตั้งและรันระบบ

### Frontend

```bash
cd frontend
npm install
npm run dev
```

เปิดที่ `http://localhost:3000`

### Backend

```bash
cd backend
cp .env.example .env
npm install
npx prisma generate
npx prisma db push
npm run start:dev
```

API จะทำงานที่ `http://localhost:4000`

ตรวจสอบสถานะ API ได้ที่:

```text
GET /health
```

## สถานะปัจจุบัน

- Frontend Dashboard: มีโครงสร้างและ Interaction เบื้องต้นแล้ว
- Next.js + React frontend: เริ่มต้นแล้ว
- NestJS backend: เริ่มต้นแล้ว
- Prisma schema: วางโครงสร้างข้อมูลหลักแล้ว
- Authentication: อยู่ระหว่างพัฒนา
- Exam API: อยู่ระหว่างพัฒนา
- Real-time events: อยู่ในแผนการพัฒนาถัดไป

## Roadmap

1. เพิ่มระบบสมัครสมาชิกและเข้าสู่ระบบ
2. เพิ่ม Role-based Access Control
3. เพิ่ม Course API และระบบลงทะเบียนเรียน
4. เพิ่ม Exam API สำหรับสร้างข้อสอบและส่งคำตอบ
5. เพิ่มการบันทึกผลสอบและวิเคราะห์คะแนน
6. เพิ่ม WebSocket สำหรับข้อมูลแบบ Real-time
7. เพิ่ม Redis และ Queue สำหรับงานเบื้องหลัง
8. เพิ่มระบบทดสอบอัตโนมัติ
9. เตรียมระบบสำหรับ Deployment
